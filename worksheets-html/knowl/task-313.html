Now we’ll compute the last number, the \(R^2\) number. We just need the first and last numbers of the SS (SSE) column. \(R^2\) is simply the first number divided by the last number from the SS (SSE) column.
The p-value takes a more complicated computation than is necessary for this exercise. In this case, it is approximately 0.0106.
