# How to convert reveal.js slides to powerpoint
## last updated 9/7/2023

1. Open the reveal.js slides in a browser.  You can do this by double clicking on the file in Microsoft File Explorer.
2. Create the PDF version by changing the end of the url of the title slide from "#/" to "?print-pdf".
3. Open the in-browser print dialog (CTRL + P in Windows, CMD + P on Mac).
4. Change the **Destination** setting to **Save as PDF**
5. Change the **Layout** to **Landscape** (if this option is available).
6. Change the Margins to None (if this option is available).
7. Enable the Background graphics option.
8. Click **Save**
9. Go to the Adobe online PDF to Powerpoint [conversion site](https://www.adobe.com/acrobat/online/pdf-to-ppt.html)
10. Upload your PDF
11. Download the PowerPoint file.
12. The conversion won't be perfect.  Open the file in Microsoft PowerPoint and make whatever changes are necessary.
