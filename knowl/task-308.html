Part 10.2.12.a.
First, we’ll fill in the df column, which stands for “degrees of freedom”. For the first entry, corresponding to the Model row, input the number of groups we have minus 1. For the last entry, corresponding to the Total row, input the sample size minus 1. For the middle entry, corresponding to the Error row, input \(\text{df}_{\text{Total}} - \text{df}_{\text{Model}}\text{,}\) in other words, the last number from the column minus the first number from this column.
Your three numbers should be such that the number from the Model row plus the number from the Error row add up to the number from the Total row.
