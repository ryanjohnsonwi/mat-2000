The Matched Pairs applet will perform the simulation similar to what you did with flipping a coin.

  • Check the Randomize box.

  • Set the number of times to Randomize to 1 and press Randomize.

  • Once the coin tosses have determined which heart rate will be in which column, the applet displays the rerandomized data (the colors show you the original column for each observation, so you should see a mix in each group now).

  • This could-have-been value for the mean difference is added to the Average Difference graph.
