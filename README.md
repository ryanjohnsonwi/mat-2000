# Worksheets for Grace College from Zybooks

### Compiled by Dr. Ryan Johnson johnsor@grace.edu

Code in this folder creates worksheets in pdf or html format using PreText.

Running the jupyter notebook <c>extract-slides.ipynb</c> in the scripts folder will create pretext files for slides, then these can then be converted into reveal.js files.  Then there is another jupyter notebook <c>fix-images.ipynb</c> that fixes the current image issues. (noted 2023 - change this code if PreText fixes this bug)
