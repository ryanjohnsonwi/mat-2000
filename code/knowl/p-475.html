You should notice that 0.382 and 0.362 are about 2 standard deviations apart and that the two-sided p-value is around 0.05, so this value (0.382) is close to the edge of values that can be considered plausible for \(\pi\text{.}\) Values between 0.362 and 0.382 are considered plausible and values larger than 0.382, or more than 2 standard deviations above 0.362, will not be plausible values for the population proportion.
